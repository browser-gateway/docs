Add, list, update, delete, and test browser provider entries. Adding via API writes to `gateway.yml` on disk atomically.

`GET /v1/providers` masks credentials before it answers: any secret-looking query parameter in a provider URL (`token`, `apiKey`, `key`, `secret`, `password` and friends), any username or password embedded in the URL, and the value of any header whose name carries a credential (such as `Authorization`) all come back as `***`. Sending a masked value straight back in a `PUT` keeps the stored secret, so a dashboard edit form can round-trip its own view safely.
