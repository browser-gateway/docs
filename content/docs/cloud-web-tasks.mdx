## What it is

One endpoint for web jobs. You say what kind of job you want and give the address, the query or the question. The project picks one of the services connected to it, checks that the answer is real (not a block page, a sign-in wall or an invented value), and tries another service when it is not. You get back the answer and a record of every service tried.

You bring the services: connect your own keys for Firecrawl, TinyFish, Exa or Jina under **Web tasks, Your services** in the dashboard. Two services are built in and need no key: plain fetch, and BrowserGateway browsers, which run on your project's own browser providers.

| Surface | Use it when |
|---|---|
| **Web tasks** (this page) | You want an answer and do not mind which service gets it |
| [Cloud Data API](/cloud-data-api) | You want our browsers directly, with no routing between services |
| [Cloud CDP endpoint](/cloud-cdp) | You drive the browser yourself with Puppeteer or Playwright |
| [Cloud MCP](/cloud-mcp) | An AI agent should use web tasks as tools |

## Request types

| Type | Name | You give | You get | Changes the site | How the answer is checked |
|---|---|---|---|---|---|
| `web.read` | Read a page | One page address | The page's readable text, as markdown, plain text or HTML | No | Real content, not a block page, sign-in wall or error page |
| `web.raw` | Raw page | One page address | The page's HTML, unchanged | No | Real content, not a block page, sign-in wall or error page |
| `web.screenshot` | Screenshot | One page address and the format | A link to the image | No | Not blank and not a block page |
| `web.extract` | Pull facts | One page address and the names of the facts you want | Each fact as a value | No | Every fact filled and found in the page |
| `web.search` | Search the web | A search phrase | Results with title, address and excerpt | No | Results came back and match the search |
| `web.answer` | Research a question | A plain question, no address | A written answer and its sources | No | Sources cited; always returned as unverified |
| `web.crawl` | Walk a site | A starting address and a page limit | The text of every page reached | No | Each page checked like Read a page |
| `web.act` | Do a task | A goal in plain words | The outcome with evidence | Can | Planned |
| `web.watch` | Watch for changes | A page and how often | A notice when it changes | No | Coming soon |

Choosing between them:

1. No page address? **Search the web** for links, or **Research a question** for a written answer.
2. Many pages of one site? **Walk a site**.
3. Only a few named values from a page? **Pull facts**. The whole page? **Read a page**.

`GET /web/v1/types` returns this list with the services that can run each type.

## Address and key

```
POST https://cdp.browsergateway.io/web/v1/tasks
Authorization: Bearer bg_YOUR_PROJECT_KEY
```

Web tasks use the project key, the same one as CDP, the Data API and MCP. The account token (`bga_...`) manages services and settings on the [Cloud REST API](/cloud-rest-api) but does not run tasks.

## Run a task

```bash
curl -X POST https://cdp.browsergateway.io/web/v1/tasks \
  -H "Authorization: Bearer $BG_PROJECT_KEY" \
  -H "Content-Type: application/json" \
  -d '{"type":"web.read","url":"https://en.wikipedia.org/wiki/HTTP"}'
```

Fields per type:

| Type | Fields |
|---|---|
| `web.read` | `url`, `format`: `markdown` (default), `text` or `html` |
| `web.raw` | `url` |
| `web.screenshot` | `url`, `format`: `png` (default) or `jpeg`, `fullPage`: `true` for the whole page |
| `web.extract` | `url`, `fields`: 1 to 25 names, for example `["price", "in stock"]` |
| `web.search` | `query` |
| `web.answer` | `question` |
| `web.crawl` | `url`, `maxPages`: 1 to 1,000, 25 when left out |

Every type also takes `prefer`:

| `prefer` | Order of services | Most spent on one request |
|---|---|---|
| `cost` (default) | Cheapest first; free services before paid ones | $0.05 |
| `speed` | Fastest first; a slow service loses even when free | $0.10 |
| `reliability` | Most likely to work first | $0.50 |

The limit counts every attempt, including ones thrown away. When no connected service fits under it, the cheapest one still gets one try. At most 3 services are tried (5 with `reliability`). The default comes from the project's web task settings.

## The answer

```json
{
  "ok": true,
  "data": {
    "runId": "6f1c2b9e-4d3a-4f7e-9a1b-2c3d4e5f6a7b",
    "type": "web.read",
    "status": "done",
    "verified": true,
    "result": { "text": "# HTTP\n\nThe Hypertext Transfer Protocol ..." },
    "took": [
      { "service": "plain-fetch", "usable": false, "reason": "the page answered HTTP 403", "ms": 310, "cost": 0 },
      { "service": "firecrawl", "usable": true, "reason": null, "ms": 1820, "cost": 380 }
    ],
    "cost": { "millicents": 380 }
  }
}
```

- `verified` says whether the checks could confirm the answer. `false` means a service answered but it could not be confirmed (Research a question is always `false`): check the sources before relying on it.
- `took` lists every service tried, in order, with why each one was kept or thrown away.
- Costs are in millicents: 1,000 millicents is one cent. They are charged by the services on your own keys, not by Browser Gateway, except BrowserGateway browsers, which count as sessions.
- `result` by type: read and raw `text`; screenshot `link` (anyone with it can open the image for 7 days), `width`, `height`, `format`; extract `fields` (name to value); search `results` (`title`, `url`, `snippet`); answer `answer` and `citations`.

## Walk a site runs in the background

A crawl answers at once with `202` and a run id, then keeps going.

```json
{ "ok": true, "data": { "runId": "8d2e...", "type": "web.crawl", "status": "running", "service": "firecrawl" } }
```

Read its progress and pages:

```bash
curl https://cdp.browsergateway.io/web/v1/tasks/RUN_ID \
  -H "Authorization: Bearer $BG_PROJECT_KEY"
```

```json
{
  "ok": true,
  "data": {
    "runId": "8d2e...",
    "status": "running",
    "verified": true,
    "result": {
      "pages": [{ "url": "https://quotes.toscrape.com/", "title": "Quotes to Scrape", "text": "..." }],
      "rejected": [],
      "completed": 8,
      "total": 12,
      "cursor": "8"
    },
    "cost": { "millicents": 3040 }
  }
}
```

- Each call returns up to 10 pages. While `cursor` is not `null`, call again with `?cursor=` set to it for the next pages.
- `status` ends as `done`, `failed` or `cancelled`. Pages that fail the checks are listed in `rejected` with the reason, not in `pages`.
- Stop a run with `POST /web/v1/tasks/RUN_ID/cancel`. Pages already read are still charged by the service.
- A run still going after one hour is stopped for you. Pages stay readable for 24 hours after a run ends.
- A run id from another project answers `404`.

## Errors

```json
{ "ok": false, "error": { "code": "no_service", "message": "Pull facts needs a service that pulls facts itself. Add a key for Firecrawl or TinyFish under Your services.", "services": ["firecrawl", "tinyfish"] } }
```

| Code | HTTP | Meaning |
|---|---|---|
| `invalid_input` | 400 | A field is missing or has the wrong shape; `issues` names it |
| `unknown_type` | 400 | No such type; `types` lists the valid ones |
| `coming_soon` | 400 | The type exists but does not run yet |
| `no_service` | 400 | No connected service can run this type; `services` names the ones that could |
| `no_usable_answer` | 502 | Every service tried was thrown away; `took` says why |
| `unauthorized` | 401 | Missing or wrong project key |
| `workspace_suspended` | 403 | The workspace is suspended |
| `not_found` | 404 | No run with this id on this project |
| `rate_limited` | 429 | The workspace's daily API limit was reached |

## Compatibility

New types, fields, result fields, error codes and services are added without changing `/web/v1`. Ignore fields you do not know, and treat a `status` or error code you do not know as a failure.

## Recent runs

`GET /web/v1/tasks?limit=50` lists the project's runs from the last 30 days: type, target, outcome, service, attempts, time and cost. Answers themselves are not kept.
